# Episode 1 text fixtures

Text artifacts for AI Survival Ep01, "How to Survive an AI Drone". They match the files Booth already has for that cut. No media, contact data, or credentials are in this folder. `lines.json` includes speech-generation ids from the episode package so the importer can see that field; they are not API keys.

| File | Role |
|---|---|
| `timeline-v3d.json` | Narration clips, beats, palettes, shorts |
| `rc8b-concat.txt` | ffmpeg concat demuxer list for the stills |
| `score-cues-v3d.md` | Music and SFX cue sheet |
| `lines.json` | Script lines. `00d_b1` is here and was cut from the timeline |
| `asr-mix-v3d.txt` | Segment transcript of the mix, `[start-end] text` |
